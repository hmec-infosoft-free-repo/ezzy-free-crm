# Machine Categories and Types

In our system, every specific machine name acts as a **Category**. This means that a broad machine type (like a Capping Machine) contains various specialized sub-types depending on its operation, automation level, and technical specifications.

## 1. The "Machine as Category" Concept
A machine is not just a single product; it is a classification. For instance, "Screw Capping Machine" is a category that encompasses several distinct variations designed for different production requirements.

---

## 2. Featured Category: Screw Capping Machine
The **Screw Capping Machine** is a primary category. Within this category, there are majorly 4 types:

### Types of Screw Capping Machines
1.  **Semi-Automatic Screw Capping Machine**
    *   Requires manual intervention for bottle placement or cap feeding.
2.  **Automatic Single Head Screw Capping Machine**
    *   Fully automated operation with a single capping head for moderate production speeds.
3.  **Automatic Multi-Head Screw Capping Machine**
    *   Features multiple capping heads (e.g., 4, 6, 8 heads) for high-speed industrial lines.
4.  **Automatic Pick and Place Type Screw Capping Machine**
    *   Uses a specialized pick-and-place mechanism for precise cap handling and torque control.
    *   Available in multiple head configurations: **4 Head, 6 Head, 8 Head, 10 Head, and 12 Head** variants.

---

## 3. Featured Category: Sticker Labeling Machine
The **Sticker Labeling Machine** is another primary category with several specialized types based on the application and automation level.

### Types of Sticker Labeling Machines
1.  **Semi-Automatic Sticker Labeling Machine**
    *   Designed for low-volume production where manual placement of the container is required.
2.  **Automatic Wrap-Around Sticker Labeling Machine**
    *   Used for applying labels that wrap around cylindrical bottles or containers.
3.  **Automatic Single-Side Sticker Labeling Machine**
    *   Specifically for applying a label to one side of flat, oval, or square containers.
4.  **Automatic Double-Side Sticker Labeling Machine**
    *   Capable of applying labels to both the front and back of a container simultaneously.
    *   *Also known as Front and Back Labeling Machine.*
5.  **Automatic Shrink Sleeve Labeling Machine**
    *   Applies a sleeve-type label that is then shrunk using a heat tunnel to fit the container shape.

---

## 4. Featured Category: Injectable Vial Line
The **Injectable Vial Line** is a high-precision turnkey solution designed specifically for pharmaceutical vials.

### Component Machines of the Vial Line
1.  **Linear/Rotary Vial Washing Machine** (Specially for glass/plastic vials)
2.  **Injectable Liquid Filling Machine** (With Nitrogen purging options)
3.  **Injectable Dry Powder Filling Machine** (For sterile powder dosing)
4.  **Vial Capping Machine** (Specialized for aluminum seals/vial caps)
5.  **Roller Inspection Machine** (For visual clarity and particle checking)
6.  **Wrap-Around Labeling Machine** (For cylindrical vial bodies)
7.  **Track and Trace Machine** (For serialization compliance)
8.  **Cartoning Machine** (For packing vials with leaflets)

---

## 5. Other Core Machine Categories
Based on industry standards and production line requirements, the following are also treated as main categories:

| Category | Common Types | Semi-Auto Available? |
| :--- | :--- | :--- |

---

## 6. Summary of Hierarchy
*   **Level 1: Machine Category** (e.g., Sticker Labeling Machine)
*   **Level 2: Machine Type** (e.g., Automatic Double-Side Labeling)
*   **Level 3: Technical Variation** (e.g., High-speed Double-Side Labeler with Camera)
